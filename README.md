# Perfumey: Perfume Store Landing Page

A simple perfume store landing page built with HTML and CSS. This is a beginner practice project to learn page layout and styling.

## Features
- Navigation bar with Home, Products, About Us, and Contact Us menu items
- Search box section
- Product cards in a box layout, each with an image and description
- Hover effect on menu items

## Built With
- HTML5
- CSS3

## Files
- `index.html`: page structure and content
- `style.css`: styling for the navbar, search box, and product boxes

## What I Practiced
- Building a page with semantic structure (header, nav, sections)
- Styling with CSS: colors, padding, borders, inline-block layout
- Hover effects using `:hover`
- Publishing a project with GitHub Pages
